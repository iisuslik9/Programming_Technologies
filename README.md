## guessing number game

Принцип единой ответственности:

NumberValidator обрабатывает проверку формата

RangeValidator обрабатывает проверку диапазона

ConsoleOutput управляет консольным вводом-выводом

Принцип открытости/закрытости:

Добавление новых валидаторов без изменения существующего кода

Реализация новых выходов (например, FileOutput) без изменения класса Game

Принцип подстановки Лисков:

Любая реализация IValidator может использоваться взаимозаменяемо

Различные реализации IOutput работают с классом Game

Принцип разделения интерфейсов:

IValidator<T> имеет единую ответственность

IOutput сосредоточен на операциях ввода-вывода

Принцип инверсии зависимостей:

Game зависит от абстракций (IOutput, IValidator)

Валидаторы, внедренные через конструктор
